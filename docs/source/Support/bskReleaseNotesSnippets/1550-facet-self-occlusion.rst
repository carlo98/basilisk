- Added :ref:`facetDragSelfOcclusionPolygonClippingEffector` and :ref:`facetSRPSelfOcclusionPolygonClippingEffector`, faceted flat-plate drag and solar radiation pressure effectors that account for planar self-occlusion between the spacecraft's own facets, computed by polygon clipping, and apply each facet force at the center of pressure of its visible region.
- Added the :ref:`facetSelfOcclusionEffectorBase`, :ref:`facetDragSelfOcclusionEffectorBase` and :ref:`facetSRPSelfOcclusionEffectorBase` base classes and the shared ``PolygonClippingOcclusion`` algorithm class, so that a new occlusion algorithm is implemented once and exposed for both drag and SRP by two thin modules.
- Added the optional :ref:`facet self-occlusion benchmark <benchmark_facet_self_occlusion>`, ``benchmarks/dynamics/benchmark_facet_self_occlusion.py``, which measures the run time of the polygon-clipping self-occlusion algorithm for drag and SRP.
